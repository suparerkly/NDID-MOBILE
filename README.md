# NDID Verify LOSE

แอป Flutter (Android, iOS และเว็บ) จำลองการยืนยันตัวตนแบบ NDID ด้วยกล้องตรวจใบหน้า แล้วซื้อประกันออนไลน์แบบจำลอง โดยมีเซิร์ฟเวอร์จำลองที่ใช้ Prisma + SQLite เก็บข้อมูล

> เป็นการจำลองเพื่อสาธิตเท่านั้น ไม่ได้เชื่อมต่อกับระบบ NDID จริง ไม่มีการตัดเงิน และไม่ออกกรมธรรม์จริง

## ขั้นตอนในแอป

1. ยอมรับเงื่อนไขการจำลองและการใช้กล้อง
2. กรอกข้อมูลส่วนตัว (ตรวจเลขตรวจสอบของบัตรประชาชน เบอร์มือถือ และอีเมล)
3. เลือกผู้ให้บริการยืนยันตัวตน (ธนาคารสมมติ)
4. สแกนใบหน้าด้วยกล้องหน้า: จัดใบหน้าในกรอบ, กะพริบตา, หันหน้าแล้วกลับมามองตรง
5. แสดง popup "ยืนยันตัวตนสำเร็จ"
6. เมนูหลัก: ซื้อประกันออนไลน์ (เลือกแบบ, ผู้รับผลประโยชน์, วิธีชำระเงินจำลอง) และดูกรมธรรม์

## การรัน

ต้องใช้ Flutter 3.24 ขึ้นไป และ Node.js 20 ขึ้นไปสำหรับเซิร์ฟเวอร์จำลอง

### 1. เซิร์ฟเวอร์จำลอง (Prisma + SQLite)

แอปเก็บผู้ใช้ ผลยืนยันตัวตน แบบประกัน และกรมธรรม์ไว้ในฐานข้อมูล SQLite ของเซิร์ฟเวอร์ในโฟลเดอร์ `server/` ต้องเปิดเซิร์ฟเวอร์ก่อนใช้แอป

ครั้งแรกให้ติดตั้งและสร้างฐานข้อมูลพร้อมแบบประกันตัวอย่าง

```bash
npm --prefix server install
```

```bash
npm --prefix server run setup
```

เปิดเซิร์ฟเวอร์ที่ `http://127.0.0.1:3000`

```bash
npm --prefix server start
```

คำสั่งอื่นที่ใช้บ่อย

- `npm --prefix server run db:reset` ล้างข้อมูลทั้งหมดแล้วใส่แบบประกันตัวอย่างใหม่
- `npm --prefix server run db:studio` เปิด Prisma Studio เพื่อดูข้อมูลในฐานข้อมูล

โครงสร้างตารางอยู่ที่ `server/prisma/schema.prisma` ถ้าแก้ไขให้รัน `npm --prefix server run setup` อีกครั้ง

### 2. แอป

```bash
flutter pub get
```

```bash
flutter run
```

ในหน้าข้อมูลส่วนตัว กด "กรอกข้อมูลตัวอย่าง" เพื่อใช้ข้อมูลสมมติแทนข้อมูลจริงได้

- **Android:** minSdk 21 อีมูเลเตอร์เชื่อมต่อเซิร์ฟเวอร์ผ่าน `10.0.2.2:3000` โดยอัตโนมัติ
- **iOS:** iOS 15.5 ขึ้นไป ต้อง build บน macOS และรันบนเครื่องจริงเพื่อใช้กล้อง
- **อีมูเลเตอร์:** ตรวจใบหน้าจริงได้ยาก จึงมีปุ่ม "ข้ามการสแกน" ซึ่งแสดงเฉพาะ debug build
- **เครื่องจริง:** เปิดเซิร์ฟเวอร์ให้รับจากเครือข่ายด้วย `HOST=0.0.0.0` แล้วรันแอปพร้อมที่อยู่ของคอมพิวเตอร์ เช่น `flutter run --dart-define=API_BASE_URL=http://192.168.1.10:3000` เซิร์ฟเวอร์ไม่มีการยืนยันสิทธิ์ ใช้เฉพาะในเครือข่ายที่ไว้ใจได้

### 3. เวอร์ชันเว็บ

```bash
flutter run -d chrome
```

หรือ build เป็นไฟล์เว็บไว้ที่ `build/web`

```bash
flutter build web --release
```

เบราว์เซอร์ใช้ Google ML Kit ไม่ได้ เวอร์ชันเว็บจึงไม่มีการตรวจใบหน้า หน้าตรวจใบหน้าจะแจ้งไว้และมีปุ่มจำลองผลแทน บนจอกว้างแอปแสดงเป็นคอลัมน์ขนาดมือถือกลางจอ

## การ build สำหรับ Google Play

ก่อนอัปโหลดครั้งแรก ให้ตรวจ `applicationId` ใน `android/app/build.gradle` เพราะเปลี่ยนไม่ได้หลังอัปโหลด

สร้างคีย์สำหรับอัปโหลด โดยรันในโฟลเดอร์ `android` แล้วเก็บไฟล์และรหัสผ่านไว้ให้ปลอดภัย

```bash
keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```

คัดลอก `android/key.properties.example` เป็น `android/key.properties` ใส่รหัสผ่าน แล้ว build

```bash
flutter build appbundle --release
```

ไฟล์ที่ได้อยู่ที่ `build/app/outputs/bundle/release/app-release.aab` ถ้าไม่มี `key.properties` จะเซ็นด้วย debug key ซึ่ง Google Play ไม่รับ

แอปต้องเชื่อมต่อเซิร์ฟเวอร์จำลองจึงจะใช้งานได้ release build อนุญาตเฉพาะ https จึงต้องนำเซิร์ฟเวอร์ขึ้นโฮสต์ที่มี https และเพิ่มการยืนยันสิทธิ์ก่อน แล้ว build ด้วย `--dart-define=API_BASE_URL=https://...`

## ข้อจำกัดด้านความปลอดภัย

- การตรวจใบหน้าทำบนเครื่องด้วย Google ML Kit ไม่บันทึกและไม่ส่งภาพออกไป
- เป็นเพียงการตรวจว่ามีใบหน้าและมีการเคลื่อนไหว ไม่ได้เทียบใบหน้ากับบัตรประชาชน และไม่กันการปลอมแปลงขั้นสูง ห้ามนำไปใช้ยืนยันตัวตนจริง
- ข้อมูลผู้ใช้ (รวมเลขบัตรประชาชน) ผลยืนยันตัวตน และกรมธรรม์ บันทึกไว้ไม่เข้ารหัสใน `server/prisma/dev.db` จนกว่าจะรัน `db:reset` ใช้เฉพาะข้อมูลตัวอย่าง
- ออกจากระบบจะล้างข้อมูลในแอปเท่านั้น ถ้ายืนยันตัวตนด้วยเลขบัตรเดิมอีกครั้ง จะเห็นกรมธรรม์ที่เคยซื้อไว้
- เซิร์ฟเวอร์จำลองไม่มีการยืนยันสิทธิ์ผู้เรียก จึงรับเฉพาะ 127.0.0.1 โดยค่าเริ่มต้น

## โครงสร้าง

- `lib/screens/` หน้าจอทั้งหมด (`face_scan.dart` เลือกหน้าตรวจใบหน้าของมือถือหรือเว็บ)
- `lib/services/api_client.dart` เรียก API ของเซิร์ฟเวอร์จำลอง
- `lib/services/liveness_checker.dart` ลำดับการตรวจใบหน้า
- `lib/services/mock_ndid_service.dart` จำลองคำขอยืนยันตัวตน
- `lib/services/validators.dart` ตรวจข้อมูลในฟอร์ม
- `server/prisma/schema.prisma` โครงสร้างฐานข้อมูล (User, Verification, InsurancePlan, PlanBenefit, Policy)
- `server/prisma/seed.js` แบบประกันตัวอย่าง
- `server/src/server.js` API ของเซิร์ฟเวอร์จำลอง
