สิ่งที่เทสต์ชุดนี้ยังไม่ครอบคลุม

ต้องใช้เครื่องจริง

  • กล้องและ ML Kit ตรวจใบหน้าจริง เครื่องเทสต์ไม่มีกล้อง E2E จึงใช้ปุ่ม "ข้ามการสแกน" (มีเฉพาะ debug build) ส่วนตรรกะ liveness ทดสอบแยกใน unit test
  • integration_test/ เดิมรันได้เฉพาะบนอีมูเลเตอร์หรือเครื่องจริง ครั้งนี้ไม่ได้รัน
  • ยังไม่ได้ build Android, iOS และเว็บ

ยังไม่มีเทสต์

  • หน้าตรวจใบหน้าเวอร์ชันเว็บ (face_scan_screen_web.dart)
  • กรณีเซิร์ฟเวอร์ไม่ตอบภายใน 10 วินาที (timeout)
  • เลขกรมธรรม์ที่สุ่มซ้ำแล้วต้องสุ่มใหม่
  • E2E ใช้ FakeAppApi ในหน่วยความจำ ส่วนการคุยกับเซิร์ฟเวอร์จริงอยู่ในชุด contract

เซิร์ฟเวอร์

  • แยกแอป Express ไปไว้ที่ src/app.js ส่วน server.js เหลือแค่เปิดพอร์ต พฤติกรรม API เหมือนเดิม

  • scripts/with-test-db.js สร้าง SQLite ชั่วคราวใหม่ทุกรอบแล้วลบทิ้ง จึงไม่แตะ dev.db
