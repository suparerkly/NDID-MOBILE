# ชุดเตรียมขึ้น Google Play

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `listing.md` | ชื่อแอป คำอธิบาย และหมวดหมู่ ไทยและอังกฤษ |
| `privacy_policy.html` | ร่างนโยบายความเป็นส่วนตัว ต้องแทนที่ค่าใน `[ ]` แล้วเผยแพร่ที่ลิงก์สาธารณะ |
| `play_console_answers.md` | ร่างคำตอบ App content และ Data safety |
| `graphics/icon_512.png` | ไอคอนหน้าร้าน |
| `graphics/feature_graphic_1024x500.png` | ภาพโปรโมต |
| `graphics/screenshots/` | ภาพหน้าจอมือถือ 1080x2160 จำนวน 8 ภาพ |
| `graphics/source/` | ต้นฉบับไอคอนและภาพโปรโมต |

## สิ่งที่ยังต้องทำ

- แทนที่ค่าในวงเล็บ `[ ]` ของนโยบายความเป็นส่วนตัว และให้ผู้รู้ด้านกฎหมายตรวจ
- เผยแพร่นโยบายความเป็นส่วนตัวที่ลิงก์สาธารณะ
- อ่านคำตอบใน `play_console_answers.md` ให้ตรงกับแบบฟอร์มจริงก่อนส่ง
- ถ่ายภาพหน้าสแกนใบหน้าจากมือถือจริงด้วย release build เพื่อเพิ่มในหน้าร้าน ชุดนี้ไม่มีภาพหน้านี้ เพราะภาพจากอีมูเลเตอร์ไม่มีใบหน้าจริงและมีปุ่มสำหรับ debug
- ขอหนังสืออนุญาตใช้ชื่อ NDID ก่อนเปิดสาธารณะ
